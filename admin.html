Adicionar uma receita

Este formulário envia a receita diretamente para a API própria (/api/recipes). É necessário o token de administração configurado na Netlify.

Como funciona: a receita é guardada em Netlify Blobs, aparece imediatamente na API e na pesquisa do site, mas não gera automaticamente uma página estática. Para uma página permanente e indexável, acrescente a receita a data/recipes.json e execute node build/build.mjs && node build/pages.mjs antes do deploy.
Não é guardado no navegador nem enviado para outro destino além da sua API.
